# Nhật ký phát triển

Thư mục này là hồ sơ kỹ thuật lâu dài của dự án.

- `CHANGELOG.md`: chức năng đã hoàn thành theo phiên bản.
- `ISSUES.md`: lỗi, rủi ro và vấn đề còn tồn tại.
- File `YYYY-MM-DD-session.md`: công việc, kiểm thử và quyết định trong từng phiên.

Runtime log của ứng dụng nằm ở `../logs/app.log`; log từng TTS/render job nằm trong thư mục `logs` của project dữ liệu tương ứng.
